storage engine · C++20 · done

An LSM-tree storage engine written from scratch in C++20. Writes hit a write-ahead log before an in-memory red-black tree; full memtables flush to immutable sorted SSTables, each with a sparse index (every 32nd key) and a bloom filter tuned to a 1% false-positive rate. Once four SSTables exist, a condition variable wakes a background thread that runs a streaming k-way merge — compaction never loads a whole table into RAM.

The write path is append-only at every step: the WAL is a sequential file, the memtable flush is one sorted streaming write, and compaction reads k files forward-only through a min-heap. Nothing seeks backwards on the write side — that is where the throughput comes from.

compaction.cpp — the streaming k-way merge. The heap holds one entry per table, so memory is O(k) regardless of how large the tables are. Duplicate keys resolve to the highest table index (most recent), and tombstones are dropped on the way out.

// K-way merge: process entries in sorted order, O(k) memory
while (!min_heap.empty()) {
    MergeEntry current = min_heap.top();
    min_heap.pop();

    // Only write if this is a new key (heap order => most recent first)
    if (current.key != last_key) {
        if (current.value != mem_table::tombstone) {
            size_t key_size   = current.key.size();
            size_t value_size = current.value.size();
            output.write(reinterpret_cast<const char*>(&key_size),   sizeof(size_t));
            output.write(reinterpret_cast<const char*>(&value_size), sizeof(size_t));
            output.write(current.key.data(),   key_size);
            output.write(current.value.data(), value_size);
            entries_written++;
        }
        last_key = current.key;
    }

    // Advance whichever iterator produced this entry
    size_t iter_idx = current.table_index;
    if (iterators[iter_idx]->next()) {
        min_heap.push({ iterators[iter_idx]->key(),
                        iterators[iter_idx]->value(), iter_idx });
    }
}

bloom_filter.h — double hashing derives every probe from a single std::hash call by rotating the 64-bit result and forcing it odd, so the second hash is always coprime with the bit-array size.

std::pair<size_t, size_t> hash(const slice& key) const {
    std::string key_str = key.toString();
    size_t h1 = std::hash<std::string>{}(key_str);
    size_t h2 = (h1 >> 32) | (h1 << 32);
    h2 = h2 | 1;              // make sure h2 is odd
    return {h1, h2};
}
