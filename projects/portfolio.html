Every page except the title card (index.html) renders the same chrome — header, sidebar, terminal dock — injected once by mountChrome() in site.js, so the shell lives in exactly one place instead of being copy-pasted across every HTML file.

Two data structures at the top of site.js feed nearly everything on the site: STATS holds every benchmark number shown anywhere (its totals field is computed at load from the project list, never hand-edited), and PROJECTS is the single array that drives the sidebar tree, the project grid, this topology graph, hover previews, the topbar status line, and the terminal's ls / cd / status commands. Adding an entry to that array is what made this very node appear in the tree, the graph, and the terminal all at once.

Each page sets two globals — SITE_ROOT and SITE_PAGE — before loading the shared script, which is how the shared code knows where the page lives and derives the terminal's prompt path automatically when a page is renamed.

site.js — adding a project is one array entry; the tree, grid, graph, and terminal all pick it up without further wiring.

var PROJECTS = [
    { id:'portfolio', name:'This Site', file:'portfolio.html',
      status:'done', real:true,
      gh:'https://github.com/1129Chengyuan/1129Chengyuan.github.io',
      // … tags, dates, roadmap — everything else derives from this
    }
];

deriveTotals() — STATS.totals is never hand-edited; it's recomputed from PROJECTS every time the page loads.

function deriveTotals() {
    var done = PROJECTS.filter(function(p){ return p.status==='done'; }).length;
    var loc = PROJECTS.reduce(function(a,p){ return a + (p.loc||0); }, 0);
    var latest = PROJECTS.map(function(p){ return p.lastTouched; })
                         .filter(Boolean).sort().slice(-1)[0] || '—';
    STATS.totals = { projects: PROJECTS.length, done: done, latest: latest };
}
